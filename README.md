   🎙️ Jarvis - Your Personal Voice Assistant

Jarvis is a simple Python-based voice assistant that listens to your voice commands, speaks back, and performs basic tasks like opening websites, playing songs from a custom library, and fetching news updates.

🚀 Features

🎧 Voice Recognition – Listens for the wake word “Jarvis” using your microphone.

🗣️ Text-to-Speech (TTS) – Uses pyttsx3 to respond verbally.

🌐 Web Navigation – Opens popular websites like Google, YouTube, Facebook, and LinkedIn through voice commands.

🎵 Music Player – Plays songs from a predefined YouTube library (musiclibrary.py).

📰 News Updates – Integrates with the News API (configurable with your own API key).

💬 Error Handling – Gracefully handles unrecognized speech and timeouts.

🧠 How It Works

Initialization – Jarvis starts and waits for the wake word “Jarvis.”

Listening Mode – Once triggered, it listens for a command (e.g., “open YouTube” or “play stealth”).

Command Execution – Executes the appropriate function such as opening a browser or playing music
